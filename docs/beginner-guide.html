ทองคำ XAU/USD คืออะไร?
พื้นฐานที่ต้องรู้ก่อนเริ่ม

ราคาทองคำวัดยังไง?

ราคาทองคำวัดเป็น ดอลลาร์ต่อออนซ์ (troy ounce)
เช่น XAU/USD = 2,650.00 หมายถึง ทอง 1 ออนซ์ราคา $2,650

ซื้อ (Buy) vs ขาย (Sell)

ราคาขึ้น = ถ้าเปิด Buy ไว้ → ได้กำไร ราคาลง = ถ้าเปิด Sell ไว้ → ได้กำไร

ในตลาด Forex/Gold สามารถทำกำไรได้ทั้งขาขึ้นและขาลง

Lot Size = ขนาดการเทรด

Lot Size ทองขยับ $1 ระดับความเสี่ยง
0.01 ได้/เสีย $0.01 ต่ำมาก
0.10 ได้/เสีย $0.10 ปานกลาง
1.00 ได้/เสีย $1.00 สูง

อะไรทำให้ราคาทองขยับ?

  • ดอลลาร์อ่อน → ทองขึ้น
  • สงคราม / วิกฤต → ทองขึ้น (safe haven)
  • Fed ขึ้นดอกเบี้ย → ทองลง
  • ข่าว NFP, CPI, FOMC → ทองขยับแรงมาก

Grid Trading คืออะไร?
หัวใจของระบบ — วางกับดักราคาเป็นชั้นๆ

แนวคิดหลัก

Grid Trading คือการวาง orders ซื้อ/ขายเป็นชั้นๆ รอบราคาปัจจุบัน เหมือน "ตาข่ายดักราคา"
เมื่อราคาแกว่งขึ้นลง bot จะเปิดและปิด orders ทำกำไรจากการแกว่งทุกรอบ

Grid Levels หน้าตาเป็นยังไง

SELL 2,680 ชั้น 3
SELL 2,670 ชั้น 2
SELL 2,660 ชั้น 1
NOW 2,650 — ราคาปัจจุบัน
BUY 2,640 ชั้น 1
BUY 2,630 ชั้น 2
BUY 2,620 ชั้น 3

ทำงานยังไง?

ราคาลงมาถึงชั้น Buy 2,640 → bot ซื้อ → รอราคากลับขึ้น → ปิดทำกำไร ✔ ราคาขึ้นไปถึงชั้น Sell 2,660 → bot ขาย → รอราคากลับลง → ปิดทำกำไร ✔ ตลาดแกว่งไปมา = bot กินกำไรทุกรอบ

Grid Spacing คำนวณจากอะไร?

Grid Spacing = ATR × ATR_MULTIPLIER

ATR คือค่าความผันผวน ยิ่งตลาดผันผวนมาก grid ยิ่งกว้าง (ปลอดภัยกว่า)

⚠
จุดอ่อนของ Grid Trading ถ้าราคาวิ่งทางเดียวไม่กลับ (เช่น ทองร่วง $100) → ขาดทุนหนัก
นี่คือเหตุผลที่ต้องมี AI Regime Detection + News Shield

Indicators ที่ Bot ใช้
เครื่องมือวัดสภาพตลาด 3 ตัวหลัก
Momentum
RSI (Relative Strength Index)
0 — Oversold 30 50 70 100 — Overbought

วัดว่าซื้อ/ขายมากเกินไปยัง
< 30 = Oversold (น่าซื้อ) | > 70 = Overbought (น่าขาย)

Volatility
ATR (Average True Range)
ต่ำ — ตลาดสงบ สูง — ตลาดผันผวน

วัดความผันผวนของราคา
ATR ต่ำ = grid แคบ, เทรดถี่ | ATR สูง = grid กว้าง, ปลอดภัยกว่า

EMA 20/50 (Exponential Moving Average)

วัดทิศทางแนวโน้มของราคา โดยเปรียบเทียบค่าเฉลี่ย 2 เส้น

EMA20 อยู่บน EMA50 = ขาขึ้น (Uptrend) → เน้น Buy EMA20 อยู่ล่าง EMA50 = ขาลง (Downtrend) → เน้น Sell EMA20 ≈ EMA50 = Sideways (Neutral) → Buy/Sell เท่ากัน

EMA20 = ค่าเฉลี่ย 20 แท่ง (ไวต่อราคา)
EMA50 = ค่าเฉลี่ย 50 แท่ง (ช้ากว่า แต่แม่นกว่า)

AI ทำหน้าที่อะไร?

Claude Code cowork อ่าน indicators ทั้ง 3 ตัว (RSI, ATR, EMA) แล้วจำแนกสภาวะตลาดเป็น 6 ประเภท จากนั้นปรับ config ของ grid ให้เหมาะกับสถานการณ์

Strong Uptrend
RSI > 65 + EMA20 > EMA50
เปิดแต่ Buy, lot × 1.5
Mild Uptrend
RSI 55-65 + EMA20 > EMA50
Buy เยอะ, Sell น้อย
Neutral
RSI 40-60 + EMA ใกล้กัน
Buy = Sell เท่ากัน
Mild Downtrend
RSI 35-45 + EMA20 < EMA50
Sell เยอะ, Buy น้อย
Strong Downtrend
RSI < 35 + EMA20 < EMA50
เปิดแต่ Sell, lot × 1.5
High Volatility
ATR ratio > 2.0
ขยาย spacing, lot × 0.5

ทำไม AI ถึงสำคัญ?

ถ้าทองเป็น uptrend แรง แต่ bot เปิด Sell grid เต็ม → ขาดทุนหนักแน่นอน
AI ช่วยบอกว่า "ตอนนี้ขาขึ้น อย่าเปิด Sell!" และปรับ grid ให้อัตโนมัติ
